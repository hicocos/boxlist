# S3 / Cloudflare R2 预览图存储

S3 用于保存生成的列表缩略图与阅读预览，不是把原文件迁移到 S3。默认关闭；在“任务中心 → 预览图 → 空间与健康 → 配置存储”中由管理员配置。

基础任务、格式与资源限制见 [预览图运维](thumb-operations.md)，完整应用备份见 [部署指南](../DEPLOYMENT.md)。

## 配置

- **存储服务**：选择“通用 S3”或“Cloudflare R2”。旧配置仍按通用 S3 处理，不自动改变读取方式。
- **Cloudflare R2**：填写 `https://<account-id>.r2.cloudflarestorage.com`，也支持 `.eu.r2.cloudflarestorage.com` 和 `.fedramp.r2.cloudflarestorage.com` 辖区端点。不要填写公开域名或桶路径。R2 固定使用 `auto` 区域与 Path-style，无需手动设置。
- **Endpoint**：S3 API 地址，不是 CDN 地址，不带对象路径、查询串或内嵌账号信息。公网需 HTTPS；私网兼容服务可使用 HTTP。云元数据和 link-local 地址被拒绝。
- **Bucket / Region / 对象前缀**：使用独立桶或专用前缀隔离预览图与其他业务对象。
- **Access Key ID / Secret Access Key**：使用仅具有目标范围所需权限的凭据。应用需要对象写入、读取、HEAD 与删除权限；连接探测和清理也会使用这些操作。
- **Path-style**：按 S3 兼容服务要求选择。
- **CDN 域名**：可选 HTTPS 地址，指向桶根或正确的绑定前缀；应用不会额外拼接 Bucket 名称。填写地址本身不会切换为公开直读。

普通配置接口不回显密钥；编辑同一目标时密钥留空可保留现有值。凭据使用本机密钥加密保存在数据库，私有密钥文件位于应用数据目录的 `derivatives/s3.key`。

“测试连接”会在配置前缀内写入随机小对象、读回、检查并删除；保存启用配置时会再次测试。公开 CDN 模式还会确认绑定域名可以读取探测对象。连接成功不代表已验证所有供应商特性、桶策略或 CDN 缓存规则。

## 写入与切换

启用后，新生成的 `thumb` 和 `reader` 写入 S3；下载与编码仍在本地临时目录进行，S3 产物不保留永久本地副本。原文件不上传、不改写。

- 已有效的本地结果仍可复用，**不会自动迁移**。要让特定目录重新写入当前目标，可创建强制重新生成任务。
- 新结果成功发布前保留旧有效结果；上传失败不会提前删除旧结果。
- 修改存储服务、Endpoint、Bucket、Region 或前缀会创建独立目标记录。旧目标凭据仍用于旧产物读取与精确清理，不要立即删除旧桶或撤销其权限。由旧通用 S3 配置切换为 R2 时需要重新填写凭据；已有产物继续使用原目标的读取方式。
- 禁用 S3 只停止后续写入；已有 S3 预览仍依赖原目标和凭据才能读取。
- 相同目标可编辑凭据完成密钥轮换；目前没有单独的旧目标管理器或后台全量迁移任务。

## 读取模式与隐私

### 通用 S3：权限代理（默认）

请求经 Boxlist 的短期票据、用户/会话、目录权限、分享、源版本和挂载校验，再由服务器从 S3 读取并校验内容后响应。桶可保持私有；支持 HEAD、Range 和条件请求。

此模式会消耗应用服务器与 S3 之间的带宽。读取具有并发和单对象大小保护，当前远端并发响应上限为 4，单对象上限为 32 MiB。不要在外层代理把私有响应改为公共缓存。

### Cloudflare R2：短期签名重定向（默认）

参考本机 `/opt/random-image-api/` 的交付方式：列表仍返回 Boxlist 票据 URL，请求到达后完成票据、用户/会话、目录权限、分享、源版本和挂载校验，再返回 `302` 到 R2 API 的 AWS SigV4 签名 URL，有效期固定为 **5 分钟**。图片内容由浏览器直接向 R2 获取，不经过应用服务器；GET 和 HEAD 分别签名，Range 由 R2 处理。

重定向响应使用 `Cache-Control: private, no-store` 和 `Referrer-Policy: no-referrer`；GET 签名还要求对象响应不缓存。签名使用 R2 API 端点，不使用自定义公开域名。生成签名不发起远程读取，也不在交付时重新校验对象摘要。

签名 URL 是短期持有者链接：获得链接的人在到期前可以免登录读取。撤销分享或修改权限会阻止再次签发，但不能立即撤回已经签发的 URL 或已下载内容。桶应保持私有。

配置页面保留端点输入和读取方式选择，不再展示 R2 端点长说明及短期持有者链接说明；相关行为见本节。2026-10-12 已在实际 R2 私有桶验收：连接探测写入/读取/HEAD/删除成功，thumb 与 reader 生成成功，302 签名跳转后的 GET/HEAD 为 200、Range 为 206，图片 SHA-256 与索引一致，浏览器解码成功；重复任务复用产物且无原图下载。无签名请求和错误本站票据被拒绝。公开 URL 未配置，未进行公开域名联网验收。

同次验收保留一条真实签名 URL 等待超过 5 分钟：旧链接返回 403；重新通过本站票据获取的新签名返回 200，图片摘要保持一致。

### 通用 S3 / Cloudflare R2：公开 URL 直读

只有明确选择公开模式才返回桶绑定域名的对象链接。链接不携带 Boxlist 票据，**持有链接者不受后续登录状态、目录密码或分享撤销约束**。需要自行配置公开域名或公开桶；应用不会替你修改桶 ACL。

R2 填写已启用公开访问的桶自定义域名或 `r2.dev` 基础 URL。程序拼接对象前缀和对象键，不额外添加桶名；不对公开 URL 签名。保存时仍验证公开地址能读取探测对象。

保密预览不得使用此模式。切回权限代理或删除源文件不能收回已经分发的公开链接、CDN 缓存或已下载图片；缓存失效策略必须由部署者管理。

## 空间与清理

上传成功并通过远端确认后才发布索引。对象键包含产物摘要，不使用原文件路径。空间统计根据应用记录的对象大小计算，不代表整个桶的实时总用量。

“清理失效输出”仅处理已记录的明确失效对象及符合保留期的未关联上传记录，不遍历桶删除其他业务对象，也不把源存储离线视为原文件删除。历史目标仍需有效凭据才能清理。不要通过桶生命周期规则随意删除还被有效索引引用的对象。

## 备份与恢复

### 网页可迁移备份

管理页面“备份与还原”中的预览图部分包含：

- S3 / R2 目标配置、供应商类型和**可迁移凭据**；
- 可用 S3 预览的对象键、摘要、尺寸、源版本和挂载路径等索引。

**不包含**图片内容、本地预览图、本机 `s3.key`、预览图任务、规则或上传日志。整个预览图备份字段支持页面密码加密；备份含可用凭据，必须设置备份密码并限制保存位置与访问权限，不可上传到公开问题或仓库。

还原时先恢复源存储，并保持对应挂载路径。程序按路径重新绑定存储 ID，保留 S3 对象键，不下载或重新上传图片；可迁移凭据使用目标实例自己的密钥重新加密，无需复制旧实例的 `s3.key`。

默认合并保留已有预览和目标配置；“覆盖”只替换匹配配置及对应索引，不删除桶对象。备份/还原不访问图片对象，因此原桶中的图片必须仍然存在且凭据可用。**只有索引无法找回已删除的图片。** 备份体积取决于索引数量，JSON 处理仍受内存约束；期间避免同时修改存储配置。

### 完整实例备份

直接备份数据库或数据卷与网页迁移备份是两回事。原数据库中的凭据依赖同一份 `derivatives/s3.key`；**必须同时备份数据库和该密钥**，否则旧凭据无法解密。还需独立保留 S3 桶对象及本地预览文件。

恢复完整数据卷后检查卷权限、源存储、桶连接和预览读取。回退到不支持 S3 预览的程序版本不会让远端结果自动转为本地可读；应先在数据副本中确认版本兼容性。
