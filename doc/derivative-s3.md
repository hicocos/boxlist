# S3 / Cloudflare R2 预览图存储

用于保存生成的缩略图和阅读预览，不迁移或修改原文件。默认关闭，在“任务中心 → 预览图 → 空间与健康 → 配置存储”中启用。

## 配置

1. 选择“通用 S3”或“Cloudflare R2”。
2. 填写 API Endpoint、Bucket、Region 和对象前缀。
3. 填写 Access Key ID / Secret Access Key，选择读取方式。
4. 测试连接并保存。

建议使用独立桶或专用前缀，凭据仅授予目标范围的读取、写入和删除权限。“测试连接”会写入小对象，读回后删除。

R2 Endpoint 使用 `https://<account-id>.r2.cloudflarestorage.com`，不要填写公开域名或桶路径；区域和 Path-style 自动配置。通用 S3 按服务商要求填写。

编辑同一目标时，密钥留空可保留现有值。凭据加密保存在数据库中，加密密钥位于应用数据目录的 `derivatives/s3.key`。

## 读取模式与隐私

| 模式 | 行为 | 注意事项 |
| --- | --- | --- |
| 通用 S3 权限代理 | 校验本站权限后由服务器读取图片 | 桶可保持私有，消耗服务器带宽 |
| R2 短期签名重定向 | 校验本站权限后跳转至 R2，由浏览器读取 | 签名链接有效期 5 分钟，持有者在到期前可读取 |
| 公开 URL 直读 | 返回桶或 CDN 的公开对象地址 | 不受后续登录、目录密码或分享撤销约束，不用于私密内容 |

签名 URL 到期前不能立即撤回，已经下载的图片也无法收回。公开模式需要自行配置公开桶或域名；填写 CDN 地址本身不会开启公开模式。

## 切换与清理

启用后，新生成的预览写入对象存储，编码仍需要本地临时空间。已有本地预览不会自动迁移，需要时可强制重新生成。

修改桶、端点或前缀后，旧预览仍依赖原目标和凭据；不要立即删除旧桶或撤销权限。关闭对象存储只停止后续写入，不会将已有远端预览转回本地。

通过“空间与健康”清理失效输出，不要直接清空桶或用生命周期规则删除仍在使用的预览。页面空间统计仅表示本程序记录的对象用量。

## 备份与恢复

### 网页备份

包含对象存储配置、可迁移凭据和预览索引，**不包含图片、本地预览、任务或规则**。请设置备份密码，勿公开备份文件。

恢复时先恢复源存储，保持原挂载路径，并确保远端对象仍存在。凭据会使用新实例的密钥重新加密，无需复制旧 `s3.key`。仅有索引无法找回已删除的图片。

### 完整实例备份

原始数据库必须与 `derivatives/s3.key` 一同备份，缺少密钥无法解密凭据。还需单独保存远端桶对象和本地预览文件。

完整步骤见 [备份与恢复](../DEPLOYMENT.md#备份与恢复)。
