# 预览图使用与运维

预览图由主 Go 服务管理，使用受资源限制的 libvips 子进程编码，不需要独立编码服务。原文件只读；默认写入应用数据卷，也可显式配置 [S3 存储](derivative-s3.md)。部署与完整备份见 [部署指南](../DEPLOYMENT.md)。

## 创建任务与阅读

1. 管理员进入一个实际存储挂载内的目录，在工具栏选择“生成预览图”，或在“任务中心 → 预览图”新建任务。
2. 选择当前目录或包含子目录，以及列表缩略图 `thumb`、阅读预览 `reader`。默认补齐缺失或变更的结果；强制重新生成会重新处理已有结果。
3. 在任务中心查看扫描、文件和各档位结果，搜索任务/文件错误，暂停、恢复、取消、重试失败或重新扫描。

暂停停止领取新工作，已领取文件继续有界处理；取消会取消该任务的在途工作。正在退出的工作结束前不能重试或删除任务。删除任务历史、关闭规则或取消任务**不等于删除已成功的预览图**。

阅读器可在画质设置中选择阅读预览或原图，缺失预览时按需回退；列表用的 480px 缩略图不用作阅读正文。网格/图片视图可刷新可见预览状态。

### 自动规则

规则需要管理员明确目录、递归范围、排除模式和周期，并**显式开启**。访客浏览不会创建生成任务。暂停规则只停止后续自动入队，已有任务需单独暂停。

任务和规则绑定源存储身份。修改源地址、根目录或账号可能使旧结果失效；不要把旧存储的索引直接赋给另一个存储。

## 支持格式与尺寸

仅处理静态 **JPEG、PNG、WebP**，根据文件内容而非扩展名识别。源文件上限为 **128 MiB / 48,000,000 像素**。GIF、APNG、动画 WebP、TIFF、SVG 不会取第一帧冒充完整预览；此限制与图标素材库支持 GIF 是不同功能。

| 档位 | 最大宽 | 最大高 | 最大像素数 |
| --- | ---: | ---: | ---: |
| `thumb` | 480 | 4096 | 2,000,000 |
| `reader` | 1600 | 12000 | 12,000,000 |

输出为有损 WebP，质量参数 `Q=90`。图片不放大、不裁剪，进行方向校正和 sRGB 色彩转换，保留透明并剥离 EXIF/GPS 等元数据。长图若缩放后无法达到阅读宽度，会返回 `long_image_requires_original`；可能只有 thumb 成功，阅读时使用原图。

质量参数不保证文件一定更小，也不保证小字阅读效果。请按实际内容比较原图与预览；不要据此删除原文件。损坏文件、超限图片、源访问失败和编码超时会在任务中显示独立结果。

## 工作并发

在“任务中心 → 预览图 → 空间与健康”设置“工作并发上限”：

- 默认 **1**，可设 **1–4**，保存后持久化且无需重启。
- 只影响后续领取；从 4 降到 1 不会取消已经领取的文件。
- 目录扫描最多一个；文件工作共享下载速率、磁盘预留和编码内存预算。工作数不等于同时编码进程数，也不保证线性加速。
- 提高并发前先确认主机资源；应用预算不能替代容器/宿主的资源隔离。公开 Compose 不预设容器内存硬上限。

## 启动配置

以下环境变量由预览图模块在启动时读取。在 Compose `environment` 中显式添加，随后用 `docker compose up -d` 重建容器配置；仅写入 `.env` 不会自动传入。

| 变量 | 默认值 | 范围与含义 |
| --- | --- | --- |
| `DERIVATIVES_ENABLED` | `true` | `false` 停止生成和返回预览关联；不删除落盘结果，原图路径不变 |
| `DERIVATIVES_BUDGET_BYTES` | `0` | 本地预览与临时工作预算；0 不设容量上限，正值须为 192 MiB 至 1 PiB |
| `DERIVATIVES_MIN_FREE_BYTES` | `5368709120` | 本地输出保留 5 GiB 空闲空间；有效范围 1 字节至 1 PiB |
| `DERIVATIVES_DOWNLOAD_BYTES_PER_SECOND` | `8388608` | 共享下载速率 8 MiB/s；有效范围 64 KiB/s 至 128 MiB/s |
| `DERIVATIVES_SCAN_INTERVAL_MS` | `250` | 扫描最短间隔；有效范围 100–60000 ms |
| `DERIVATIVES_RUN_START_HOUR` | `0` | 开始小时，0–23 |
| `DERIVATIVES_RUN_END_HOUR` | `0` | 结束小时，0–23；与开始相同时全天，可跨午夜 |
| `DERIVATIVES_MAX_JOBS` | `1000` | 任务数量上限，1–10000 |
| `DERIVATIVES_MAX_ITEMS` | `100000` | 每任务工作项上限，含目录，1–1000000 |
| `DERIVATIVES_MAX_RULES` | `100` | 规则数量上限，1–1000 |

执行时段按进程所在时区计算，需特定时区时在容器中设置 `TZ`。时段外不领取新工作，不强杀在途文件。并发上限通过管理页面配置，不是上述启动变量。

本地输出同时受总预算、空闲空间与工作预留限制。启用 S3 写入后不套用本地输出的 5 GiB 空闲阈值，但下载与编码仍需本地临时空间；S3 不是零磁盘模式。空间保护暂停不消耗文件失败重试次数，空间恢复后可继续。预览图数量与空间统计不是整个磁盘或整个 S3 桶的用量。

## 权限与持久化

- 默认根目录为 `/opt/openlist/data/derivatives`，位于应用数据卷中；`artifacts/` 保存本地产物，`work/` 是临时工作目录。运行用户为 UID/GID 1001。
- 图片读取使用短期票据，并重新校验用户、目录权限、分享有效性和存储绑定。不要分享带票据的 URL；已经下载的像素无法远程收回。
- 权限代理返回私有缓存策略；不要在反向代理中覆盖成公共缓存，或直接暴露产物目录。S3 公开 CDN 模式是另一个安全边界，见 [读取模式](derivative-s3.md#读取模式与隐私)。
- 命中预览时不会为每次读取探测原文件。外部变更的发现依赖目录元数据或任务/规则刷新，不能把预览仍可读取视为原文件仍存在的证明。
- 一个数据库与预览根目录只运行一个后端进程；持久任务检查点不是多副本分布式租约。

## 空间检查与清理

在“空间与健康”先检查可清理数量，再选择具体范围：

- **清理过期临时工作**：处理超过 24 小时且没有活动工作占用的临时目录。
- **清理失效输出**：处理已确认被替换、源已变更/删除或本地缺失的失效记录，以及符合保留期的未关联残留。

检查不触发完整源扫描，也不把离线源或失败目录当作已删除。外部原图删除须通过成功、完整的刷新扫描确认；成功发布新版本和应用内文件操作也会标记旧预览失效。S3 空间按记录的对象大小统计，不遍历整个桶。

仍有效的手动结果不按 TTL/LRU 自动淘汰。任务历史与预览文件独立管理，不要用删除数据库行或手动清空数据目录替代界面清理。清理前确认备份策略，尤其是公开 CDN 缓存不一定随对象删除立即失效。

## 备份与限制

本地预览的数据库索引和产物文件应保持一致；完整停止服务后备份数据卷是较简单的方式。网页备份不包含本地预览图。S3 原始数据库备份还必须保留 `derivatives/s3.key` 和远端对象，详见 [S3 备份与恢复](derivative-s3.md#备份与恢复)。

- 不跨挂载处理，不支持别名、引用、crypt、负载均衡等虚拟存储路径。
- 目录扫描受驱动完整列表返回、深度和工作项上限约束，不承诺无限规模流式扫描。
- 源版本依赖驱动提供的大小、时间或可靠哈希。同大小、同修改时间且无可靠内容哈希的覆盖可能无法识别，需要强制重新生成。
- 源盘限流、网络速度、编码资源和内容都会影响处理时间；没有通用压缩比或吞吐保证。
- Dockerfile 提供 Linux 编码运行环境；自行替换镜像或工具版本后需自行确认编码能力与资源限制仍可用。
