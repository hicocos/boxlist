# 预览图使用说明

预览图用于加快列表和图片阅读，不修改原文件。默认保存在应用数据卷，也可使用 [S3 / Cloudflare R2](derivative-s3.md)。

## 生成与阅读

1. 管理员在目录工具栏选择“生成预览图”，或进入“任务中心 → 预览图”新建任务。
2. 选择目录范围及列表缩略图 `thumb`、阅读预览 `reader`。
3. 在任务中心查看进度，暂停、取消或重试失败任务。

默认补齐缺失或已变更的预览；“强制重新生成”会处理已有结果。删除任务历史不会删除生成的图片。

阅读器和普通图片预览优先使用阅读预览，仍可选择或下载原图。列表缩略图不会替代阅读正文；预览缺失时按权限加载原图。

自动规则需管理员指定目录、周期并启用，访客浏览不会触发生成。暂停规则只停止后续任务，已有任务需单独暂停。

## 支持范围

- 静态 JPEG、PNG、WebP；不处理动画图片及其他格式。
- 原文件上限：128 MiB、4800 万像素。
- 输出为 WebP，不放大、不裁剪，保留透明并移除 EXIF/GPS 元数据。

| 档位 | 最大宽 | 最大高 | 最大像素数 |
| --- | ---: | ---: | ---: |
| `thumb` | 480 | 4096 | 2,000,000 |
| `reader` | 1600 | 12000 | 12,000,000 |

超限长图可能需要使用原图。预览不保证一定更小，也不能替代原文件备份。不跨存储挂载处理，别名、crypt 等虚拟存储不支持生成。

## 并发与空间

在“空间与健康”中调整工作并发，默认为 1，可设为 1–4。提高并发前确认服务器内存、磁盘和源存储限流情况。

常用启动配置通过 Compose `environment` 传入，修改后重建容器：

| 环境变量 | 默认值 | 用途 |
| --- | --- | --- |
| `DERIVATIVES_ENABLED` | `true` | 是否启用预览图功能 |
| `DERIVATIVES_BUDGET_BYTES` | `0` | 本地容量预算，0 为不限 |
| `DERIVATIVES_MIN_FREE_BYTES` | `5368709120` | 本地输出保留 5 GiB 空闲空间 |
| `DERIVATIVES_DOWNLOAD_BYTES_PER_SECOND` | `8388608` | 共享下载速率 8 MiB/s |
| `DERIVATIVES_RUN_START_HOUR` | `0` | 开始小时 |
| `DERIVATIVES_RUN_END_HOUR` | `0` | 结束小时，与开始相同时全天运行 |

执行时段使用容器时区。S3 输出也需要本地临时空间；空间不足时任务暂停，恢复空间后可继续。

## 清理与备份

在“空间与健康”中先检查，再选择清理过期临时工作或失效输出。有效预览不会因删除任务历史而自动清除，不要直接删除数据库记录或产物目录。

图片读取仍校验用户、目录和分享权限。不要公开数据目录、转发带票据的链接，或将私有响应改为公共缓存。

完整备份应包含数据库及本地产物；S3/R2 还需保存密钥和桶对象。网页备份不包含图片文件，详见 [备份与恢复](../DEPLOYMENT.md#备份与恢复)。
