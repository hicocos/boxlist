# 历史说明：独立图标服务

> 早期 Python 图标 sidecar 与 `/icon-library/` 接入方案已不作为 boxlist 的当前部署方式。安装请阅读 [快速开始](quickstart.md)；现行 API、鉴权、配额与许可证见 [后端变更](backend-changes.md)。

当前集成版在原生 Go 后端提供同源 `/icon/`，不需要第二个图标容器、独立服务域名或额外 token。历史服务源码与部署示例仅供维护参考，不应与当前集成安装混用。

## 通用安全要求

- 写入必须使用真实启用管理员身份与精确 HTTPS Origin；反向代理应原样传递 Authorization 和 Origin，不得伪造来源或配置固定凭据。
- 素材 API 与错误路径不能回落到 SPA HTML；私有原图、数据库、staging 和 trash 不得配置为静态公开目录。
- 上传进入素材库不等于已保存图标选择。提交结果不确定时保留原请求标识，核对目录后重试，避免制造重复提交。
- 删除前核对最新已保存引用；无法验证时拒绝删除。浏览器锁不能协调其它浏览器或外部 API 的全部写入。
- immutable 预览已被浏览器缓存时，源端删除不能撤回已下载内容。

旧服务数据和已保存引用需要单独迁移，不能仅复制预览或改 URL。备份与恢复要求见 [迁移说明](migration.md)，不要将凭据、实际数据库或上传原图加入公开仓库。
