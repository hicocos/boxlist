# 历史说明：单独替换静态前端

> 本文对应早期仅替换 OpenList 静态前端的方案，已不作为 boxlist 的推荐安装方式。当前部署请阅读 [快速开始](quickstart.md)；原生图标模块、上游基线与许可证见 [后端变更](backend-changes.md)。

仅复制 `dist/` 不包含 boxlist 的 Go 后端，也不会让官方后端自动获得 `/icon/` 上传、删除与素材目录接口。需要完整功能时使用集成镜像。

如仍需单独替换静态前端：

- 先确认目标版本与实际数据挂载，备份配置和完整数据；不要覆盖账号、权限或存储设置。
- 核验发行包校验和，确认 `index.html`、`assets/`、`static/` 完整，不能只复制入口文件。
- `dist_dir` 必须使用目标容器可访问的路径；修改时保留其它配置字段。
- 重启目标实例以刷新缓存的 HTML 模板，检查资源 MIME 类型，避免把 SPA HTML 200 当成资源成功。
- 界面配置和浏览器偏好不会随前端文件自动迁移，见 [迁移与备份](migration.md)。
