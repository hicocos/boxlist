# 历史方案：静态前端与独立图标服务

> 此候选方案已由 boxlist 原生单容器方案取代，不是当前安装说明，也不代表计划中的独立域名连接功能已实现。当前部署见 [快速开始](quickstart.md)，技术范围与许可证见 [后端变更](backend-changes.md)。

早期方案将预编译前端与图标 sidecar 分开发行。当前推荐集成镜像：完整前端与原生 Go 图标模块同源运行，使用专属 Docker 命名卷持久化数据，不要求新用户手工复制前端或创建宿主机目录。

仍适用的发行原则：固定版本、提供校验文件与对应源码、保留许可证、审核素材再分发授权，并将首次安装与已有数据迁移分开。静态前端包不包含原生后端能力，不能当作完整功能部署。
