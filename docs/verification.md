# 验收清单与边界

本文是 boxlist 的通用验收清单，不是特定机器的操作记录或当前发行版已通过的声明。安装见 [快速开始](quickstart.md)，后端范围与限制见 [后端变更](backend-changes.md)。CI 与发行状态以对应版本的实际结果为准。

## 构建与包装

- 使用锁文件安装依赖，运行 `pnpm run test:ux`、`pnpm run lint` 与完整前端构建。
- 运行 Go 模块与路由测试，实际构建根 Dockerfile，检查镜像版本与完整嵌入资源。
- 检查安装脚本、Compose 与发行工作流。语法检查、dry-run 和 Dockerfile 静态检查不能替代实际镜像构建或启动。

## 隔离运行

使用独立命名卷、唯一测试容器名称和仅回环端口，不接触业务数据。验证：

- 原生健康接口、公开设置与页面资源正常；JS、CSS、WASM 不是 SPA HTML 200。
- 容器以非 root 用户运行，主进程为原生 Go 后端，私有路径不公开。
- 实际 HTTPS Origin 下真实管理员登录、PNG 上传、原请求标识幂等重试、预览解码和配置保存。
- 匿名、错误 Origin、禁用或降权用户，以及已撤销凭据的写入被拒绝。
- 已保存引用阻止删除；解除引用后可删除，并读回目录和源端预览确认结果。
- 重启后设置与素材状态持久化。若使用随机端口映射，重启后重新读取实际映射。

上传、删除等写入只使用明确的测试素材，结束后清理自己创建的测试资源。日志可能包含初始管理员信息，分享前必须脱敏。

## 界面与发布

检查桌面与手机布局、首页与子目录、搜索、预览、返回定位和图标管理；模拟移动视口不能替代真机手势验收。公开接口成功不等于管理员写入通过，隔离 fixture 也不等于真实鉴权验收。

发布前检查源码、Git 历史与归档中的凭据、实例配置和私有数据，审查第三方素材授权，并提供对应源码与许可证。只能报告实际执行的检查及未覆盖范围；本地通过不代表 CI、镜像发布、生产迁移或其它架构已验证。
