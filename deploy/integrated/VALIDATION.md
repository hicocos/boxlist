# 历史验证说明

> 早期包装与隔离运行记录不作为当前版本的发布或生产验收证明。boxlist 当前安装见 [快速开始](../../docs/quickstart.md)，通用验收见 [验证清单](../../docs/verification.md)，后端维护范围与许可证见 [后端变更](../../docs/backend-changes.md)。

维护者应针对待发布的确切源码和镜像重新执行脚本、Compose、工作流检查、完整镜像构建及隔离运行验收。静态检查、mock harness 或 dry-run 不能替代真实原生鉴权、素材写入、私有路径保护和重启持久化测试。

测试使用专属数据卷与独立容器，不访问业务数据；报告必须明确版本、实际执行结果和未覆盖范围，并移除凭据及机器信息。本地验收不代表镜像已发布、生产已迁移或其它架构已验证。
